Install the lab (needs an Ubuntu virtual machine with root and git):
  sudo apt install -y git      # skip if git is already installed
  git clone https://github.com/it-waves/devops-ai && cd devops-ai/academy/lab
  sudo install -m 755 lab65.sh /usr/local/sbin/
  source shortcuts65.sh   # gives you the short name lab used in the video
  lab up                  # builds /opt/lab65/work (your repository) and /opt/lab65/origin.git (the shared copy)
  lab check               # five FAIL lines at the start; your goal is five PASS lines
  lab down                # cleanup when finished
Without the shortcut, use: sudo lab65.sh up | check | down
Your task (in /opt/lab65/work): 1 run ./check.sh, read the failure, and fix the bug in shop.sh in a new commit  2 turn on the gate: git config core.hooksPath .githooks  3 git push origin main (the gate must let it through)  4 create an annotated tag v1.0.0 (git tag -a v1.0.0 -m "First release") and git push origin v1.0.0  5 write one word in /opt/lab65/answers.txt: which part of the version number you raise for a bug fix only (major, minor or patch).
If git asks who you are: git config --global user.name "Your Name" and git config --global user.email you@example.com
Run it only in your own virtual machine. It creates only /opt/lab65; lab down removes it, and you remove the installed script with: sudo rm /usr/local/sbin/lab65.sh
