Lesson 13 of the DevOps Engineering Bootcamp. Set up a disposable Linux virtual machine you can break, delete and rebuild: your options (VirtualBox, Multipass, WSL 2, cloud), sizing, how to download VirtualBox and the Ubuntu Server image, a live screen recording of the VirtualBox new-machine wizard, logging in over SSH with a key, real SSH output, common errors, and snapshots. Includes a pass/fail rubric and a hands-on task.

Honest notes: the download pages are real screenshots; the VirtualBox wizard is a real screen recording and the SSH output is real, both from a Linux sandbox (VirtualBox 7.0, Linux build; the website now offers a newer version, so yours will differ slightly). The sandbox cannot start virtual machines, so the walkthrough stops after the machine is created. The Windows VirtualBox installer, the Multipass commands and the "Connection timed out" message are not captured here. The hands-on task is unverified until you run it yourself.
