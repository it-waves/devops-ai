Lesson 13 of the DevOps Engineering Bootcamp. Set up a disposable Linux virtual machine you can break, delete and rebuild: your options (VirtualBox, Multipass, WSL 2, cloud), sizing, how to download VirtualBox and the Ubuntu Server image, a live screen recording of the VirtualBox new-machine wizard, then a hands-on lab: power on, log in, walk around, save a file, power off, take a snapshot, break the machine on purpose, and restore it. Then log in over SSH with a key, read real SSH output, and learn the common errors. Includes a pass/fail rubric and a hands-on task.

Honest notes: the download pages are real screenshots. The VirtualBox wizard and its Snapshots tab are real screen recordings from a Linux sandbox (VirtualBox 7.0, so yours will look slightly newer). That sandbox cannot start VirtualBox machines, so the power-on, login, walk-around, power-off, break and restore steps are recorded on a real Ubuntu 24.04 system running in an emulator (QEMU), and the snapshot commands shown there are QEMU's equivalents of VirtualBox's Take and Restore buttons. The Ubuntu installer checklist, the Windows VirtualBox installer, the Multipass commands and the Connection timed out message are drawn or described, not captured. The hands-on task is unverified until you run it yourself.
