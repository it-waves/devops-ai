Lesson 27 of the DevOps Engineering Bootcamp, the second lesson of the Linux administration masterclass. Every server is made of files, so you learn to create, read, copy, move, find and edit them safely. You see mkdir -p and touch, how to read a file with cat, head, tail, wc and file, how cp, mv and rm work (and why there is no undo), how to find a file with find, and then a full vim session: normal, insert and command mode, dd and u, searching with a slash, saving with :wq and quitting without saving with :q!. You finish with common myths, a six-point pass or fail rubric and six tasks to do in your own virtual machine.

Practice: work only inside a practice folder in your own Ubuntu 24.04 virtual machine, so nothing important is at risk. rm has no undo, so list a name with ls before you delete it. Notes and files: github.com/it-waves/devops-ai, folder academy/lesson27.
