Lesson 14 of the DevOps Engineering Bootcamp. Learn what a computer actually stores and how Linux reads it, with every idea shown live in a real terminal: bits and bytes, hexadecimal, how bytes become text (ASCII and UTF-8), telling a text file from a program, bytes versus characters, the hidden Windows line-ending bug (CRLF), absolute and relative paths, environment variables and export, and the PATH variable (fixing "command not found"). Includes a pass/fail rubric and a hands-on task to repeat in the virtual machine from Lesson 13.
