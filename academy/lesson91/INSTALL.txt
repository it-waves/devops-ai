Install the lab (needs an Ubuntu virtual machine with root, a JDK, Maven, python3, curl, internet access, ~3 GB free memory, ~1.5 GB disk):
  sudo apt install -y openjdk-21-jdk-headless maven python3 curl
  git clone https://github.com/it-waves/devops-ai && cd devops-ai/academy/lab
  sudo install -m 755 lab91.sh /usr/local/sbin/
  source shortcuts91.sh   # gives you the short name lab used in the video
  lab up                  # downloads Sonatype Nexus Repository Community Edition 3.98.1 (~525 MB), starts it on port 8081, writes /opt/lab91
  lab check               # five FAIL lines at the start; your goal is five PASS lines (needs: export NEXUS_PASS='your Nexus admin password')
  lab down                # stops Nexus and removes everything when finished
Without the shortcut, use: sudo --preserve-env=NEXUS_PASS lab91.sh up | check | down
Your tasks (inside /opt/lab91/shop; also in /opt/lab91/TASKS.txt):
  0 open http://localhost:8081, log in as admin with the first password from /opt/lab91/sonatype-work/nexus3/admin.password, choose your own password, finish the wizard (you read and accept the license yourself)
  1 repos     in Nexus create two maven2 (hosted) repositories: corp-snapshots (version policy Snapshot, Allow redeploy) and corp-releases (Release, Disable redeploy)
  2 snapshot  export NEXUS_PASS='your password'; mvn -B -s settings.xml deploy  (version 1.0.0-SNAPSHOT); then change pom.xml to 1.0.0 and deploy the release
  3 again     deploy 1.0.0 a second time; it fails: save the 'status code' line into conflict.txt; copy the SHA-1 of the release jar from Browse into sha1.txt
  4 next      change the version to 1.0.1 and deploy it
  5 why       why.txt: one sentence with the word release and one of immutable, reproducible, overwrite, changed
Run it only in your own virtual machine. lab down removes /opt/lab91 and the nexus91 user; remove the installed script with: sudo rm /usr/local/sbin/lab91.sh
