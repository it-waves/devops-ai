Lesson 18 of the DevOps Engineering Bootcamp, in the computer networking masterclass. Learn how ports let one computer run many network programs, the difference between TCP and UDP, the three-way handshake, and how to read connection states (LISTEN, ESTAB, TIME-WAIT). Every idea is checked live in a real terminal: well-known ports, a listening web server, a held connection, a UDP message, a refused connection and an address already in use. Includes a symptom checklist, a pass/fail rubric and a hands-on task to repeat in the virtual machine from Lesson 13.
