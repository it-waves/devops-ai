Install the lab (needs an Ubuntu virtual machine with root, a JDK, Maven, python3 and internet access to Maven Central for the build plugins):
  sudo apt install -y openjdk-21-jdk-headless maven python3
  git clone https://github.com/it-waves/devops-ai && cd devops-ai/academy/lab
  sudo install -m 755 lab90.sh /usr/local/sbin/
  source shortcuts90.sh   # gives you the short name lab used in the video
  lab up                  # builds /opt/lab90: a project, a repository with a login on port 8091, pass.txt and TASKS.txt
  lab check               # five FAIL lines at the start; your goal is five PASS lines
  lab down                # stops the server and cleans up when finished
Without the shortcut, use: sudo lab90.sh up | check | down
Your five tasks (inside /opt/lab90/shop; also written in /opt/lab90/TASKS.txt):
  1 server   settings.xml: id corp, username dev, password ${env.CORP_PASS}
  2 mirror   settings.xml: id corp, mirrorOf libs, url http://localhost:8091
  3 lock     chmod 600 settings.xml (no password inside any file)
  4 build    export CORP_PASS=$(cat /opt/lab90/pass.txt); mvn -B -s settings.xml clean package ends in BUILD SUCCESS
  5 why      why.txt: one sentence with the words pom and git (or commit)
Run it only in your own virtual machine. lab down removes /opt/lab90; remove the installed script with: sudo rm /usr/local/sbin/lab90.sh
