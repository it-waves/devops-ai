Lesson 90 of the DevOps Engineering Bootcamp, the sixth lesson of Maven. Your build works on your laptop and fails on the server with HTTP 401, Unauthorized: the company repository needs a login. You learn what a repository and a mirror are, how mirrorOf matches by id, why the pom (which lives in git) and your own settings.xml (in your home folder, never in git) are different files, and how the server id links a password to a mirror. You then learn three rules for keeping the password safe: never in the pom or any file in git, refer to an environment variable with the dollar-brace env syntax, and lock files with chmod 600. In the live demo you see the real 401, give Maven the password from a locked file, and prove the password is in no file. Then you set it up yourself: five checks, all must pass.

Get the lab: github.com/it-waves/devops-ai, in academy/lab (lab90.sh and shortcuts90.sh). Install with: sudo install -m 755 lab90.sh /usr/local/sbin/ then run lab up, lab check and lab down after loading the short name with: source shortcuts90.sh (without it, use sudo lab90.sh up, check, down). You need an Ubuntu virtual machine with root, a JDK, Maven and python3 (for example: sudo apt install -y openjdk-21-jdk-headless maven python3) and internet access to Maven Central for the build plugins; lab check downloads them each time. The lab starts a small local repository server with a login on port 8091, writes a project into /opt/lab90, and lab down stops the server and removes the folder. Only run it in your own virtual machine.

Honest notes: the terminal segments are real recordings on Ubuntu 24.04 with Maven 3.9.11 and OpenJDK 21. The company repository in the demo is a small local server I started with a login, not a real repository manager such as Nexus or Artifactory; Maven behaves the same way, including the 401. The password on screen is a throwaway demo value that only exists in my recording environment. My recording computer cannot reach Maven Central, so the plugins came from a local copy built from Ubuntu's packaged Maven files through an extra mirror that is not shown. I did not cover Maven's encrypted passwords step by step, only mentioned them. The ideas, task, rubric and quiz screens are labelled illustrations, not captures. The lab was run end to end before this lesson: it fails 0 of 5 at the start, passes 5 of 5 after a reference solution, and lab down leaves nothing behind. On your machine the plugins download from Maven Central, which I could not test, and only one style of solution was tested, so a different valid approach could be judged wrongly by the checker. The narration is synthetic speech. Your own run is unverified until you do it.
