Lesson 51 of the DevOps Engineering Bootcamp, the fifth lesson of the Python for DevOps masterclass. You make a script fail well with three habits: exceptions, logging and retries. Every demo is typed live on Ubuntu 24.04: an int("eight") traceback read from the bottom, a script with try, except, else and finally that handles a missing file and bad JSON, a logging script whose debug, info, warning and error levels you turn down with sed, and a retry loop with back off that survives a flaky API and gives up with exit code 1. The lesson ends with a lab and checker, a six-point pass or fail rubric and six tasks to do in your own virtual machine.

The checker was tested with a reference solution and with failing files, but your own run of the lab is unverified until you do it.
