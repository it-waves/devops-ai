Lesson 38 of the DevOps Engineering Bootcamp, the second lesson of the Bash scripting masterclass. A script is only useful when it can take input. You learn four ways to feed one, each in a real demo on Ubuntu: variables (assignment with no spaces, braces to end a name, and a default value with colon dash), positional arguments ($1, $#, $@ and quoting an argument that contains a space), reading input with read (from the keyboard and from a pipe) and command substitution with $( ). A short backup script then combines the ideas. The lesson ends with common myths, a six-point pass or fail rubric and six tasks to do in your own virtual machine.
