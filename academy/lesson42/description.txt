Lesson 42 of the DevOps Engineering Bootcamp, the sixth lesson of the Bash scripting masterclass. Scripts fail, so a good script must notice, stop safely, clean up and report what happened. You learn it in real demos on Ubuntu: exit codes and the dollar question mark variable, returning your own code with exit, strict mode with set dash e u o pipefail, cleanup with a trap on EXIT, timestamped logging to standard error, and allowing an expected failure with or true. One short script then combines them all. The lesson ends with common myths, a six-point pass or fail rubric and six tasks to do in your own virtual machine.
