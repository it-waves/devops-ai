Lesson 52 of the DevOps Engineering Bootcamp, the sixth lesson of the Python for DevOps masterclass. You turn a script into a proper command line tool that a pipeline can trust: arguments read and checked by argparse, a result reported as an exit code (0 success, 1 failure, 2 wrong usage), and two output channels, standard out for results and standard error for problems. Every demo is typed live on Ubuntu 24.04: a 16-line port checker, its free -h help, an open port and a closed port with echo $? after each, a bad port value that argparse rejects with exit code 2, and the shell operators the redirect of standard error to /dev/null, && and || making decisions from the exit code alone. The lesson ends with a lab and checker, a six-point pass or fail rubric and six tasks to do in your own virtual machine.
