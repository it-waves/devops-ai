Lesson 32 of the DevOps Engineering Bootcamp, the seventh lesson of the Linux administration masterclass. Software on a server arrives in packages, and on Ubuntu you manage them with apt and dpkg. You read the repository list and its suites, compare the installed and candidate version of a package, ask the package database what is installed, which package owns a file and which files a package put on disk, and preview an install, a removal and an upgrade with the simulate flag, so you can read the plan before anything changes. You learn the routine for update, install, upgrade, remove, purge and autoremove, and how to add software safely. You finish with common myths, a six-point pass or fail rubric and six read-only or simulate-only tasks to do in your own virtual machine.

Practice: work only in your own Ubuntu 24.04 virtual machine. The tasks only read or simulate, so nothing is installed or removed. Notes and files: github.com/it-waves/devops-ai, folder academy/lesson32. The next lesson covers disks, filesystems and mounts.

Honest notes: every terminal segment is a real recording of real commands on Ubuntu 24.04, including sudo apt-get update, install, remove and autoremove of the small cowsay package (I removed it again afterwards). The apt-get -s commands simulate and change nothing. The recording computer reaches the Ubuntu archive over https, so the repository address in the recording is https, while yours may show http. The update downloaded only a small part, because I removed one list beforehand so there was something to fetch. Package versions and the count of upgradable packages come from the recording computer, so yours will differ. Typing is timed to the narration, and the yellow highlights were added afterwards. Your own run is unverified until you do it.
