Install the lab (needs an Ubuntu virtual machine with root and a JDK):
  sudo apt install -y openjdk-21-jdk-headless      # skip if jar --version already works
  git clone https://github.com/it-waves/devops-ai && cd devops-ai/academy/lab
  sudo install -m 755 lab82.sh /usr/local/sbin/
  source shortcuts82.sh   # gives you the short name lab used in the video
  lab up                  # builds /opt/lab82 with a buggy class (Cart.java), its test (CartTest.java), and TASKS.txt
  lab check               # five FAIL lines at the start; your goal is five PASS lines
  lab down                # cleanup when finished
Without the shortcut, use: sudo lab82.sh up | check | down
Your five tasks (inside /opt/lab82; also written in TASKS.txt):
  1 compile: javac -d out/main src/main/com/cloudcart/Cart.java   and   javac -cp out/main -d out/test src/test/com/cloudcart/CartTest.java
  2 run the test before fixing anything: java -cp out/main:out/test com.cloudcart.CartTest > test-before.txt
  3 fix the discount bug in Cart.java, then rebuild main
  4 run the test again into test-after.txt, then pack the main classes only: jar cf cloudcart.jar -C out/main .
  5 answers.txt with exactly three lines: failed test exits with: non-zero   build output folder: out   jar holds: compiled classes
Run it only in your own virtual machine. lab down removes /opt/lab82; remove the installed script with: sudo rm /usr/local/sbin/lab82.sh
