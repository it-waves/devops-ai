Install the lab (needs an Ubuntu virtual machine with root, python3 and curl):
  sudo apt install -y python3 curl     # skip if already installed
  git clone https://github.com/it-waves/devops-ai && cd devops-ai/academy/lab
  sudo install -m 755 lab67.sh /usr/local/sbin/
  source shortcuts67.sh   # gives you the short name lab used in the video
  lab up                  # builds /opt/lab67 and starts CloudCart as ONE process (a monolith) on 127.0.0.1:8080
  lab check               # four FAIL lines at the start; your goal is four PASS lines
  lab down                # stops the app and removes /opt/lab67
Without the shortcut, use: sudo lab67.sh up | check | down
Your mission: split the monolith into a backend service (port 5000) and a frontend service (port 8080), as separate processes, then write answers.txt.
Commands you will use: ss -ltn (who is listening), curl -s URL (ask a server), cat start.sh (read the script).
Run it only in your own virtual machine. It uses ports 8080 and 5000 on 127.0.0.1 and creates only /opt/lab67. Remove the installed script with: sudo rm /usr/local/sbin/lab67.sh
