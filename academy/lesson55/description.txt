Lesson 55 of the DevOps Engineering Bootcamp, the ninth lesson of the Python for DevOps masterclass. You build a real utility and prove that it works, putting the whole masterclass together: data files, functions, a command line tool with exit codes, and tests. Every demo is typed live on Ubuntu 24.04: a validate function that returns a list of errors, a command line tool that reports every problem and exits 0 (valid), 1 (problems) or 2 (file cannot be read), and a pytest suite that tests the edges (port 65535 and 65536) with parametrize. You then break the code on purpose and watch the edge test fail (red, then green). The lesson ends with a lab whose checker also runs your tests against a deliberately broken version, a six-point pass or fail rubric and six tasks to do in your own virtual machine.

Honest notes: every terminal segment is a real recording of real commands on Ubuntu 24.04 with Python 3.12.3 and pytest 9, run in a private mount setup on the recording computer. The example files (svccheck.py, services.json and test_svccheck.py) were prepared before recording and shown with cat and head, and pytest was installed in the virtual environment beforehand, so the pip install step is described, not shown. The overview cards are illustrations, not captures. Typing is timed to the narration, and the yellow highlights were added afterwards. The checker was tested with a reference solution, an empty folder and a weak test file, but your own run of the lab is unverified until you do it.
