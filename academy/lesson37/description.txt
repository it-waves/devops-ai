Lesson 37 of the DevOps Engineering Bootcamp, the first lesson of the Bash scripting masterclass. Before you write a script you must understand how the shell reads a line. You see the four steps (split into words, expand, run, exit status), then four real demos on Ubuntu: how a script runs (shebang, bash hi.sh, the execute bit and chmod), quoting (single quotes, double quotes and the space in a file name trap), expansion (tilde, command substitution, wildcards, braces and arithmetic) and the environment (a shell variable versus an exported one, and PATH). The last demo covers exit status with $?, && and ||. The lesson ends with common myths, a six-point pass or fail rubric and six tasks to do in your own virtual machine.
