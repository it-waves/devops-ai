Install the lab (needs an Ubuntu virtual machine with root and bash; ShellCheck is a useful extra: sudo apt install shellcheck):
  git clone https://github.com/it-waves/devops-ai && cd devops-ai/academy/lab
  sudo install -m 755 lab46.sh /usr/local/sbin/
  source shortcuts46.sh   # gives you the short name lab used in the video
  lab up                  # builds the four broken scripts in /opt/lab46 (a second)
  lab check               # four FAIL lines at the start; your goal is four PASS lines
  lab down                # cleanup when finished
Without the shortcut, use: sudo lab46.sh up | check | down
Run it only in your own virtual machine. It creates only the folder /opt/lab46; lab down removes it, and you remove the installed script with: sudo rm /usr/local/sbin/lab46.sh
The scripts are in /opt/lab46/bin: archive.sh, backup.sh, count_errors.sh, setup.sh. Edit them with vim or sed, and change one thing at a time.
