Lesson 15 of the DevOps Engineering Bootcamp. Learn the main parts of a server and how each one fails: CPU, memory, disk, network, services and logs. Every idea is shown live in a real terminal: finding and stopping a runaway process, reading memory with free, filling and freeing a disk, running a web server and telling "connection refused" from a 404, and finding the cause in a log with tail and grep. Includes a four-question troubleshooting routine, a pass/fail rubric and a hands-on task to repeat in the virtual machine from Lesson 13.

Honest notes: every terminal segment is a real recording of real commands on Ubuntu 24.04 (the typing is timed to the narration, and the yellow highlights were added afterwards). Two demos use a safe stand-in: the memory demo caps the program at 200 MB with ulimit to mimic a small server, and the disk demo uses a tiny 10 MB practice disk held in memory so nothing real can fill up. The demo user is called student. The hands-on task is unverified until you run it yourself.
