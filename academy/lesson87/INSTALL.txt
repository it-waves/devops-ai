Install the lab (needs an Ubuntu virtual machine with root, a JDK, Maven and internet access to Maven Central):
  sudo apt install -y openjdk-21-jdk-headless maven
  git clone https://github.com/it-waves/devops-ai && cd devops-ai/academy/lab
  sudo install -m 755 lab87.sh /usr/local/sbin/
  source shortcuts87.sh   # gives you the short name lab used in the video
  lab up                  # builds /opt/lab87: a jar that cannot run, and TASKS.txt
  lab check               # five FAIL lines at the start; your goal is five PASS lines
  lab down                # cleanup when finished
Without the shortcut, use: sudo lab87.sh up | check | down
Your five tasks (inside /opt/lab87/shop; also written in /opt/lab87/TASKS.txt):
  1 jar plugin manifest   mainClass cloudcart.Hello, so java -jar target/cart-config-1.0.0.jar prints a line
  2 properties            app.env=dev and app.greeting=Welcome, resource filtering on: prints [dev] Welcome from CloudCart
  3 profile               id prod sets app.env to prod: mvn -B clean package -Pprod prints [prod] Welcome from CloudCart
  4 reproducible          project.build.outputTimestamp with a fixed date: two clean builds give an identical jar
  5 prove it              mvn -B clean package, then sha256sum target/cart-config-1.0.0.jar > sha.txt
Run it only in your own virtual machine. lab down removes /opt/lab87; remove the installed script with: sudo rm /usr/local/sbin/lab87.sh
