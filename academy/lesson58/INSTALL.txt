Install the lab (needs an Ubuntu virtual machine with root and git):
  sudo apt install -y git      # skip if git is already installed
  git clone https://github.com/it-waves/devops-ai && cd devops-ai/academy/lab
  sudo install -m 755 lab58.sh /usr/local/sbin/
  source shortcuts58.sh   # gives you the short name lab used in the video
  lab up                  # builds /opt/lab58/app: a repository with a change to commit, junk files and a file committed by mistake
  lab check               # four FAIL lines at the start; your goal is four PASS lines
  lab down                # cleanup when finished
Without the shortcut, use: sudo lab58.sh up | check | down
Your task (in /opt/lab58/app): 1 create .gitignore for debug.log, secrets.env and build/  2 stop tracking cache.tmp but keep the file  3 commit only the app.conf change (a clear message; notes.txt must stay uncommitted; .gitignore may be in the commit)  4 write one number in /opt/lab58/answers.txt: how many commits touched app.conf before yours.
Run it only in your own virtual machine. It creates only /opt/lab58; lab down removes it, and you remove the installed script with: sudo rm /usr/local/sbin/lab58.sh
