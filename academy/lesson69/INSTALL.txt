Install the lab (needs an Ubuntu virtual machine with root, python3 and curl):
  sudo apt install -y python3 curl     # skip if already installed
  git clone https://github.com/it-waves/devops-ai && cd devops-ai/academy/lab
  sudo install -m 755 lab69.sh /usr/local/sbin/
  source shortcuts69.sh   # gives you the short name lab used in the video
  lab up                  # builds /opt/lab69 and starts CloudCart: the REST API on 127.0.0.1:5000
  lab check               # five FAIL lines at the start; your goal is five PASS lines
  lab down                # stops the app and removes /opt/lab69
Without the shortcut, use: sudo lab69.sh up | check | down | status
Your mission, all with curl against http://127.0.0.1:5000, working inside /opt/lab69:
  1. read the API version from a response header (curl -I) and add a line to answers.txt:  version: X.Y
  2. ask for the product list as CSV with the Accept header and save it as products.csv
  3. time /api/fast and /api/report with curl -w '%{http_code} %{time_total}\n' -o /dev/null, then add to answers.txt:  slow: /api/...
  4. write smoke.sh: optional URL argument (default http://127.0.0.1:5000/api/products); exit 0 on success, non-zero on any error, including a 404 and a server that is down (hint: curl -sf)
  5. send any request with the header  X-Request-Id: lab69-trace  so it appears in api.log
Commands you will use: curl -v, curl -I, curl -H 'Name: value', curl -w, curl -f, echo $?, tail api.log
Run it only in your own virtual machine. It uses ports 5000 and 8080 on 127.0.0.1 and creates only /opt/lab69. Remove the installed script with: sudo rm /usr/local/sbin/lab69.sh
