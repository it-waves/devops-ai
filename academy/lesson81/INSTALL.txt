Install the lab (needs an Ubuntu virtual machine with root and a JDK):
  sudo apt install -y openjdk-21-jdk-headless      # skip if jar --version already works
  git clone https://github.com/it-waves/devops-ai && cd devops-ai/academy/lab
  sudo install -m 755 lab81.sh /usr/local/sbin/
  source shortcuts81.sh   # gives you the short name lab used in the video
  lab up                  # builds /opt/lab81 with a crashing program (Checkout.java), a log (app.log), and TASKS.txt
  lab check               # five FAIL lines at the start; your goal is five PASS lines
  lab down                # cleanup when finished
Without the shortcut, use: sudo lab81.sh up | check | down
Your five tasks (inside /opt/lab81; also written in TASKS.txt):
  1 compile Checkout into out/: javac -d out src/com/cloudcart/Checkout.java
  2 run it and save only the error output: java -cp out com.cloudcart.Checkout 2> crash.txt
  3 save every ERROR line of the log: grep ERROR app.log > errors.txt
  4 save how many ERROR lines there are: grep -c ERROR app.log > count.txt
  5 answers.txt with exactly three lines: top exception: IllegalStateException   root cause: NumberFormatException   bad value: x5
Run it only in your own virtual machine. lab down removes /opt/lab81; remove the installed script with: sudo rm /usr/local/sbin/lab81.sh
