Install the lab (needs an Ubuntu virtual machine with root and a JDK):
  sudo apt install -y openjdk-21-jdk-headless      # skip if javac -version already works
  git clone https://github.com/it-waves/devops-ai && cd devops-ai/academy/lab
  sudo install -m 755 lab77.sh /usr/local/sbin/
  source shortcuts77.sh   # gives you the short name lab used in the video
  lab up                  # builds /opt/lab77 with two tiny programs (Greeter.java and Broken.java) and a TASKS.txt
  lab check               # five FAIL lines at the start; your goal is five PASS lines
  lab down                # cleanup when finished
Without the shortcut, use: sudo lab77.sh up | check | down
Your five tasks (inside /opt/lab77; also written in TASKS.txt):
  1 compile Greeter (javac Greeter.java) and save java Greeter Ada into run.txt
  2 run java Greeter with no name and save its exit code (echo $?) into exit.txt
  3 compile Broken.java and save the error message into error.txt (javac Broken.java 2> error.txt)
  4 fix Broken.java (one character), compile it, run it, and save the output into broken.txt
  5 answers.txt with exactly three lines: public class: file name   exit code: 0   java takes: class name
Run it only in your own virtual machine. lab down removes /opt/lab77; remove the installed script with: sudo rm /usr/local/sbin/lab77.sh
