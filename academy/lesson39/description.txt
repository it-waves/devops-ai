Lesson 39 of the DevOps Engineering Bootcamp, the third lesson of the Bash scripting masterclass. A script becomes useful when it can decide, choose and repeat. You learn four tools, each in a real demo on Ubuntu: if and else with the test command (square brackets and exit status), tests for files, strings and numbers (including the unquoted empty variable trap), the case statement with a default branch, for and while loops, and functions that you call with arguments. A small health check script then combines a function, a test, a loop and arithmetic. The lesson ends with common myths, a six-point pass or fail rubric and six tasks to do in your own virtual machine.
