Install the lab (needs an Ubuntu virtual machine with root and a JDK):
  sudo apt install -y openjdk-21-jdk-headless      # skip if jar --version already works
  git clone https://github.com/it-waves/devops-ai && cd devops-ai/academy/lab
  sudo install -m 755 lab80.sh /usr/local/sbin/
  source shortcuts80.sh   # gives you the short name lab used in the video
  lab up                  # builds /opt/lab80 with a source file (Hello.java), a web folder (war/), and TASKS.txt
  lab check               # five FAIL lines at the start; your goal is five PASS lines
  lab down                # cleanup when finished
Without the shortcut, use: sudo lab80.sh up | check | down
Your five tasks (inside /opt/lab80; also written in TASKS.txt):
  1 compile Hello into out/: javac -d out src/com/cloudcart/Hello.java
  2 build a runnable jar, run it, save the output: jar cfe app.jar com.cloudcart.Hello -C out .   then   java -jar app.jar > jar-run.txt
  3 build a war: jar cf shop.war -C war .
  4 save its contents: jar tf shop.war > war-list.txt
  5 answers.txt with exactly three lines: jar runs with: java -jar   war needs: a servlet container   manifest holds: main class
Run it only in your own virtual machine. lab down removes /opt/lab80; remove the installed script with: sudo rm /usr/local/sbin/lab80.sh
