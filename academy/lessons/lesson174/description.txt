Lesson 174 of the DevOps Engineering Bootcamp. Your build is green, but the jar sits in a folder called target, and nobody else can use it. In this lesson Cloud Cart's core library, cart-core, gets a real home in Nexus Repository. You learn the difference between a snapshot and a release, create a snapshot repository that allows redeploy and a release repository that refuses it, build a deployer role and user that can do one job and nothing else, and configure Maven so the repository IDs match and no password is ever stored in a file. Then you ship: a snapshot twice, a release once, an attempt to overwrite the release that Nexus refuses with a 409, and finally you fetch your files back by path and by search.
