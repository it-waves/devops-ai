Lesson 178 of the DevOps Engineering Bootcamp. A green build is not a safe release. In this lesson you watch a real Jenkins pipeline protect CloudCart: a failing test stops the line before anything is published, a smoke test checks the running application and not just the build, a manual approval guards production, and a blue-green switch moves users to the new version only after it has proved itself. You see a secret masked in the console, a deployer identity that can upload but not delete, a bad release that never reaches users, and a rollback done by promoting an older version, with no rebuild.
