Lesson 173 of the DevOps Engineering Bootcamp. Every build downloads the same libraries from the internet, and your own code has no safe home. One server fixes both: a repository manager. In this lesson you learn the three kinds of Nexus repository, hosted, proxy and group, then set up a real Nexus Repository live from a fresh install, secure it, and prove it works: a 401 with anonymous access off, a library fetched from Maven Central then served from cache in milliseconds, and our own file stored and read back through one group address.

Honest notes: the browser and terminal are a real continuous recording of Sonatype Nexus Repository Community Edition 3.98.1 running on a throwaway lab server, with Maven Central as the real remote. The setup wizard includes accepting the Sonatype end user license agreement and a required base telemetry notice: the Community Edition sends a small daily usage report to Sonatype, and if it cannot be sent for 30 days the server becomes read only. Read the license for yourself before you use it at work. The password shown belongs to the throwaway lab server. The coloured boxes and labels on top are overlays added for teaching. The narration is synthetic speech. The plan, concept, mistakes, your-turn and recap screens are labelled illustrations, not captures. Use your own machine only.
