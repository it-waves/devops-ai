Lesson 48 of the DevOps Engineering Bootcamp, the second lesson of the Python for DevOps masterclass. You learn the five Python building blocks you will use in every DevOps tool: types, collections, conditions and loops, functions, and modules. Every demo is typed live on Ubuntu 24.04: the Python REPL with int and str (and the classic trap where port == "8080" is False because environment variables are strings), lists and dictionaries (append, indexing, get with a default, and a KeyError), a script with a for loop and if/else, a function with parameters and return, and imports (the json module, your own file as a module, the main guard, and ModuleNotFoundError). The lesson ends with a lab and checker, a six-point pass or fail rubric and six tasks to do in your own virtual machine.
