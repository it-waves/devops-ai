Lesson 54 of the DevOps Engineering Bootcamp, the eighth lesson of the Python for DevOps masterclass. You learn to write cloud SDK code with least privilege. Every demo is typed live on Ubuntu 24.04: a least privilege IAM policy (list one bucket, get objects only inside it), a small audit script that flags a star in Action or Resource and exits with code 1 so a pipeline can block it, boto3 code that lists objects in a bucket and catches ClientError, all run against moto, a free mock of AWS, so no cloud account is needed. You also learn how boto3 finds credentials (environment variables, the credentials file, then a role) and why a key never belongs in your code. The lesson ends with a lab whose checker uses moto, a six-point pass or fail rubric and six tasks to do in your own virtual machine.
