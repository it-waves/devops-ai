Lesson 44 of the DevOps Engineering Bootcamp, the seventh lesson of the Bash scripting masterclass. Scripts get run twice: a scheduler fires again, or a failed job is retried. Learn to write idempotent scripts that give the same result every time, and use ShellCheck to find mistakes before you run anything. Watch six real Ubuntu 24.04 terminal demos, then do the lab on your own virtual machine.

Honest notes: the terminal sections are real recordings on Ubuntu 24.04 with ShellCheck 0.9.0. In the recordings an environment setting hides ShellCheck's web links so that the output fits the screen; ShellCheck normally prints them. The title cards, rubric and quiz are illustrations, not captures. This lesson is for learning, and a clean ShellCheck result does not make a script safe to run in production.
