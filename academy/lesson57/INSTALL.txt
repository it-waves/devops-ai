Install the lab (needs an Ubuntu virtual machine with root and git):
  sudo apt install -y git      # skip if git is already installed
  git clone https://github.com/it-waves/devops-ai && cd devops-ai/academy/lab
  sudo install -m 755 lab57.sh /usr/local/sbin/
  source shortcuts57.sh   # gives you the short name lab used in the video
  lab up                  # builds /opt/lab57 with a shared repository, origin.git, with one commit
  lab check               # four FAIL lines at the start; your goal is four PASS lines
  lab down                # cleanup when finished
Without the shortcut, use: sudo lab57.sh up | check | down
Your task: clone /opt/lab57/origin.git into /opt/lab57/work/team, add notes.txt with one commit of your own, then write answers.txt (line 1: first 7 characters of the root commit hash, line 2: how many commits your clone has).
Run it only in your own virtual machine. It creates only the folder /opt/lab57; lab down removes it, and you remove the installed script with: sudo rm /usr/local/sbin/lab57.sh
