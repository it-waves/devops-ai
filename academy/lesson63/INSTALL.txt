Install the lab (needs an Ubuntu virtual machine with root and git):
  sudo apt install -y git      # skip if git is already installed
  git clone https://github.com/it-waves/devops-ai && cd devops-ai/academy/lab
  sudo install -m 755 lab63.sh /usr/local/sbin/
  source shortcuts63.sh   # gives you the short name lab used in the video
  lab up                  # builds /opt/lab63/work: a repository with a messy situation
  lab check               # four FAIL lines at the start; your goal is four PASS lines
  lab down                # cleanup when finished
Without the shortcut, use: sudo lab63.sh up | check | down
Your task (in /opt/lab63/work): 1 discard the junk edit in start.sh (git restore) so the working folder is clean  2 find the lost commit "Add retry setting" with git reflog and bring it back  3 git revert the shared commit "Add debug flag" (do not rewrite history)  4 write one number in /opt/lab63/answers.txt: how many commits main has now.
If git asks who you are: git config --global user.name "Your Name" and git config --global user.email you@example.com
Run it only in your own virtual machine. It creates only /opt/lab63; lab down removes it, and you remove the installed script with: sudo rm /usr/local/sbin/lab63.sh
